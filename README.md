🧱 MineSkin Viewer

A simple and modern Minecraft skin viewer powered by the MineSkin API
.

Search for a Minecraft username and instantly preview their skin directly in your browser.

✨ Features

🔎 Search Minecraft usernames

🧍 Minecraft skin preview

🖼️ High-resolution skin view

⬇️ Skin download

🔗 Open skin directly

📱 Responsive design

🌙 Dark interface

⚡ No framework required

🛠️ Tech Stack

HTML5

CSS3

Vanilla JavaScript

MineSkin API

🚀 Getting Started

Clone the repository:

git clone https://github.com/YOUR-USERNAME/mineskin-viewer.git
cd mineskin-viewer


Then simply open:

index.html


in your browser.

No build process or dependencies are required.
